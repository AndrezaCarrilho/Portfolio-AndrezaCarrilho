# 🎨 Portfólio Andreza Carrilho

Portfólio pessoal desenvolvido com Next.js e Tailwind CSS, com identidade visual inspirada em galerias de arte — verde musgo, marrom e tipografia elegante. Mais do que uma lista de projetos, é um espaço com história e personalidade.

🔗 **[portfolio-andreza-carrilho.vercel.app](https://portfolio-andreza-carrilho.vercel.app)**

---

## 🚀 Tecnologias

- [Next.js 15](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) *(animações)*
- [Lucide React](https://lucide.dev/) *(ícones)*
- Deploy na [Vercel](https://vercel.com/)

---

## ✨ Seções

- **História** — trajetória acadêmica e profissional
- **Obras** — projetos com status, tecnologias e links
- **Estudos** — cursos e especializações
- **Contato** — WhatsApp, LinkedIn, GitHub e e-mail

## 💻 Como Rodar Localmente

```bash
# Clone o repositório
git clone https://github.com/AndrezaCarrilho/Portfolio-AndrezaCarrilho

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse em `http://localhost:3000`
